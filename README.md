# Task 4: Git Version Control DevOps Project

## Objective
Demonstrate Git version control best practices using Git and GitHub.

## Tools
- Git
- GitHub
- Ubuntu WSL

## Concepts Demonstrated
- Repository initialization
- Main, dev, and feature branches
- Commits and meaningful commit messages
- Pull requests and merging
- Merge conflict resolution
- .gitignore
- Git tags and releases
- Git stash

## Project Structure
- README.md: Project overview and documentation
- .gitignore: Excludes unnecessary files
- docs/git-workflow.md: Git workflow and interview notes
- scripts/hello.sh: Demonstration shell script

## Workflow
1. Create a GitHub repository.
2. Create and develop changes in feature branches.
3. Merge approved changes into dev using pull requests.
4. Merge tested changes into main using pull requests.
5. Tag a release using a version number.

## Run the Demo
bash scripts/hello.sh

## Outcome
Learn and demonstrate version control workflows and Git best practices.
